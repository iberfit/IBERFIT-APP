# RELEASE NOTES · IBERFIT V7.3

## Objetivo
Aumentar interactividad y navegación real sin cambiar la estética aprobada de V7.2.

## Cambios
1. CTA principal del Home enruta según modalidad.
2. Cliente presencial: CTA lleva a Semana.
3. Cliente híbrido/online: CTA abre la primera sesión ejecutable.
4. Botón Sesión de navegación abre la primera sesión ejecutable si existe.
5. Si no hay sesión ejecutable, Sesión redirige a Semana.
6. Sesiones clicables mantienen acceso por mouse y teclado.

## No tocado
- Estética V7.2.
- Apps Script.
- Google Sheets.
- api.js.
- Cloudflare Function.
- Contratos submitFeedback / submitCheckin / semanaId.
